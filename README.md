## Начало работы

Откройте `r-for-bioinformatics.Rproj` в RStudio через File → Open Project. Все пути в заданиях считаются от корня проекта.

Для работы нужны R, RStudio, Quarto и пакеты `knitr`, `rmarkdown`, `tidyverse`, `palmerpenguins`. Для третьего практикума требуется `dplyr` версии не ниже 1.1.1.

``` r
install.packages(c("knitr", "rmarkdown", "tidyverse", "palmerpenguins"))
```

## Выполнение заданий

На первом занятии выполняйте задания в `01-r-basics.R`, затем перенесите исходные данные и решения в самостоятельно созданный `report_1.qmd`.

Для второго и третьего занятий создайте отдельные документы `report_2.qmd` и `report_3.qmd`. Сохраняйте отчёты в корне проекта, ответы на вопросы оформляйте текстом, вычисления — блоками R.

Перед сдачей нажмите Render и проверьте полученный HTML. Код должен выполняться последовательно и самостоятельно создавать все необходимые объекты.

## Просмотр материалов

Чтобы собрать практикумы в HTML, нажмите Render в открытом `.qmd` или выполните из корня проекта:

``` bash
quarto render
```

Готовые HTML находятся в `_output/`.
