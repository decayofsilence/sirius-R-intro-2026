## Начало работы

Откройте `r-for-bioinformatics.Rproj` в RStudio через File → Open Project. Сохраняйте документы в корне проекта, чтобы относительные пути в заданиях работали без изменений.

Для работы нужны R, RStudio, Quarto и пакеты `tidyverse`, `palmerpenguins`, `rmarkdown`. Quarto входит в современные версии RStudio; при работе без RStudio его нужно установить отдельно.

Недостающие пакеты можно установить через Tools → Install Packages в RStudio. Вероятнее всего RStudio автоматически определит нужные пакеты и предложит их установить при работе в документе. Можно установить пакеты заранее, выполнив команду в консоли R (вкладка Console):

``` r
install.packages(c("tidyverse", "palmerpenguins", "rmarkdown"))
```

Для большинства заданий точные версии R и пакетов несущественны: обычно достаточно относительно свежих версий.

## Выполнение заданий

На первом занятии выполняйте задания в `01-r-basics.R`, затем перенесите исходные данные и решения в самостоятельно созданный `report_1.qmd`.

Во втором и третьем практикумах записывайте решения непосредственно в соответствующие `.qmd`. Можно сохранить исходные имена файлов или переименовать их в `report_2.qmd` и `report_3.qmd` для единообразия.

Перед сдачей нажмите Render и проверьте полученный HTML. Код должен выполняться последовательно и самостоятельно создавать все необходимые объекты.

## Сборка HTML

В RStudio откройте нужный `.qmd` и нажмите Render.

Без RStudio команды выполняют в системном терминале из корня проекта — папки, содержащей `_quarto.yml`. Для сборки одного документа укажите его имя:

``` bash
quarto render 02-tables-and-dplyr.qmd
```

Для сборки всех документов проекта выполните:

``` bash
quarto render
```

Quarto автоматически использует настройки из `_quarto.yml` в обоих случаях. Готовые HTML будут сохранены в директорию `_output/`.
